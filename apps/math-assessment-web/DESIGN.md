# 수학 수행평가 아이디어 아카이브

교사는 수학 주제와 학생의 수행 방식을 고르고, 사례를 열어 원문 표와 채점기준을 확인한다. Airtable의 필드 중심 탐색을 참고해 조건 선택, 결과 목록, 원문 근거를 순서대로 배치한다.

- 제목에는 고운돋움, 목록과 필터에는 Pretendard를 쓴다.
- 본문 `#0b2545`, 선택·링크 `#1d4ed8`, 필터 배경 `#eff6ff`, 구분선 `#d8e3f0`을 공통 토큰으로 쓴다.
- 좁은 화면에서는 주제와 방법, 사례명과 분류 근거를 세로로 읽는다. 선택 상태에 테두리와 배경을 쓰고 키보드 포커스를 표시한다.
- 평가명과 출처를 목록 앞쪽에 두고, 근거 표현은 각 사례에서 펼쳐 본다. 설치 버튼은 첫 화면의 탐색 버튼 아래에 둔다.
- 성취기준 비교는 교육과정 원문, 같은 코드가 적힌 과제 목록, 두 과제 선택, 수행 내용과 채점표 비교 순으로 진행한다. 선택한 과제는 비교 링크에 담고, 기존 비교함은 개별 과제 상세에서 계속 이용한다.
- 수식·병합 오류를 원문과 대조한 표는 원문 그림을 먼저 읽는다. 대응이 확인된 추출 표만 접어서 보존하고, 나머지 표와 설명은 계속 표시한다. 원문 페이지 전체와 한글 문서를 PDF로 렌더링한 자료는 캡션에서 구분한다. 그림 로딩이 실패하면 추출 표와 안내를 보여 주며, 표 폭·글자 확대·전체 화면과 인쇄를 지원한다.
- 성취기준 필터는 교육과정, 해당 교육과정의 수학 과목, 학기 순으로 배치한다. 같은 과목명과 코드라도 교육과정별 기준 문장을 구분하고, 교육과정을 바꾸면 과제 선택을 비운다. 좁은 화면에서는 필터를 세로로 배치한다.
- 라이브러리에서 학기를 다른 조건보다 먼저 고른다. 학기를 바꾸더라도 과목·지역·검색어를 유지하고, 목록과 상세에는 자료에서 확인한 학년도와 학기를 함께 적는다.
- AI 연결 안내는 공통 메뉴와 첫 화면에서 사용설명서의 해당 영역으로 연결한다. ChatGPT·Claude의 상세 안내는 제품별 버튼으로 구분하고 GitHub 새 탭 이동을 알린다. 모바일 메뉴는 줄바꿈해 안내 버튼이 가로 스크롤 뒤에 숨지 않게 한다.
