# ChatGPT에서 수학 수행평가 아카이브 연결하기

확인 기준: 2026년 11월 9일. [공통 시작 안내와 활용 질문](TEACHER_AI_GUIDE.md)

**PC 웹브라우저에서 ChatGPT에 로그인한 뒤, 사용자 MCP 서버를 플러그인으로 추가합니다.** 설치 파일이나 GitHub 계정은 필요 없습니다.

## 1. 먼저 연결 메뉴를 여세요

1. [ChatGPT 플러그인 화면](https://chatgpt.com/plugins)을 엽니다.
2. 추가 버튼 **+**를 누릅니다.
3. 사용자 MCP 서버 추가(**Add custom MCP server**)를 선택합니다.

이 순서는 [OpenAI 공식 연결 안내](https://developers.openai.com/plugins/deploy/connect-chatgpt)의 현재 경로입니다. 등록 화면이 없으면 아래 ‘메뉴가 보이지 않을 때’를 확인하세요. 기존 인터넷 강좌의 메뉴 위치와 다를 수 있습니다.

## 2. 값을 입력하세요

| 화면 항목 | 입력할 값 |
| --- | --- |
| 이름 | `수학 수행평가 아카이브` |
| 설명 | `공개 평가계획의 수행 내용·채점표·성취기준·원문 그림을 읽고 비교합니다.` |
| 연결 | 공개 HTTPS 서버 URL을 입력하는 방식 |
| 서버 URL | `https://suhaeng-math.vercel.app/api/mcp` |
| 인증 | **없음 / No authentication** |

URL 복사용:

```text
https://suhaeng-math.vercel.app/api/mcp
```

Tunnel이나 로컬 명령 실행은 선택하지 않습니다. API 키·비밀번호·별도 OAuth 클라이언트 값도 필요 없습니다. 전송 방식 선택 항목이 있다면 Streamable HTTP를 사용합니다.

플랫폼의 연결 위험 안내와 읽기 도구 목록을 확인한 뒤 생성(**Create as a plugin**)을 완료합니다. 생성된 플러그인을 설치하는 화면이 이어지면 설치까지 마칩니다. 현재 공식 절차는 [연결·도구 확인](https://developers.openai.com/plugins/deploy/connect-chatgpt), 설치 후 사용 방식은 [공식 플러그인 사용 안내](https://learn.chatgpt.com/docs/plugins)에 있습니다.

이 아카이브는 공개 평가계획 조회 전용입니다. 자료 쓰기·삭제 도구와 선생님의 AI 계정에 로그인하는 기능은 없습니다. 서버의 도구는 아래 여섯 개입니다.

| 표시되는 도구 | 하는 일 |
| --- | --- |
| `get_archive_scope` | 현재 공개 범위와 과목·기간 확인 |
| `search_assessments` | 학년도·학기·과목·지역·검색어로 찾기 |
| `get_assessment_item` | 실제 과제의 수행 내용과 채점표 읽기 |
| `get_achievement_standards` | 공식 성취기준과 연결 과제 찾기 |
| `compare_assessments` | 실제 과제 2~4개 비교 자료 읽기 |
| `get_original_preview` | 제공되는 원문 그림 확인 |

## 3. 새 대화에서 아카이브를 선택하세요

1. 설치 후 **새 대화**를 시작합니다.
2. 입력창에서 **@**를 입력하고 방금 추가한 ‘수학 수행평가 아카이브’를 선택합니다.
3. 아래 질문을 붙여 넣습니다.

```text
선택한 수학 수행평가 아카이브의 get_archive_scope를 실제 호출해줘.
공개 과제 수, 사례 수, 학교 수, 학년도·학기, 조회 시각을 알려줘.
도구 호출이 실패하면 추측한 숫자를 답하지 말고 오류를 알려줘.
```

도구 실행과 범위 응답이 확인되면 [수업 준비 질문 예시](TEACHER_AI_GUIDE.md#4-수업-준비에-바로-쓰는-질문)로 이어 갑니다. ChatGPT가 자동으로 도구를 선택하지 않으면 **@로 아카이브를 다시 지정하고 실제 조회를 요청**하세요. [OpenAI의 사용·선택 안내](https://learn.chatgpt.com/docs/plugins)

GitHub 저장소 주소나 웹앱 첫 화면 주소만 채팅에 붙이면 MCP 연결 설정이 되지는 않습니다. 자료를 읽었다는 답변에서는 실제 도구 호출과 공식 출처를 함께 확인합니다.

## 4. 메뉴가 보이지 않을 때

| 상황 | 확인할 순서 |
| --- | --- |
| 플러그인 화면에 사용자 MCP 추가가 없음 | 계정과 선택한 워크스페이스를 확인합니다. 개인 계정과 학교 조직의 권한은 다를 수 있습니다. |
| 설정에 앱·커넥터·개발자 모드 등 다른 이름만 보임 | 메뉴 개편 가능성이 있습니다. 현재 [공식 연결 절차](https://developers.openai.com/plugins/deploy/connect-chatgpt)와 화면을 대조합니다. 없는 메뉴를 찾느라 계속 설정을 바꾸지 마세요. |
| 학교 계정에서 추가·사용이 막힘 | 관리자에게 사용자 MCP 생성과 플러그인 사용 권한을 문의합니다. 아래 요청문을 복사할 수 있습니다. |
| 유료 구독인데 메뉴가 없음 | 구독 종류만으로 이 기능의 제공을 보장할 수 없습니다. 현재 계정·조직 정책을 먼저 확인합니다. 이 안내는 확인되지 않은 요금제별 지원표를 제공하지 않습니다. |
| 당장 연결 기능을 쓸 수 없음 | [웹앱](https://suhaeng-math.vercel.app/cases)에서 직접 찾거나, 이미 Codex를 사용한다면 [별도 연결 안내](MCP_CONNECTION.md)를 따릅니다. |

조직의 플러그인 사용·MCP 생성 권한은 [OpenAI 관리자 안내](https://learn.chatgpt.com/docs/enterprise/apps-and-connectors)에 설명되어 있습니다. **로컬 Codex에 등록한 설정은 ChatGPT 웹에 자동 등록되지 않습니다.** 두 환경의 연결 방식은 [공식 MCP 안내](https://learn.chatgpt.com/docs/extend/mcp)에서 구분합니다.

관리자에게 전달할 문안:

```text
수업 준비용 공개 수학 수행평가 아카이브를 ChatGPT에서 사용하고 싶습니다.
서버: https://suhaeng-math.vercel.app/api/mcp
연결: Streamable HTTP, 인증 없음
기능: 공개 범위·사례·성취기준·채점표·원문 그림 조회와 2~4개 과제 비교
자료 수정·삭제 기능이나 개인 AI API 키 입력은 없습니다.
우리 워크스페이스에서 플러그인 사용과 사용자 MCP 추가가 가능한지,
관리자가 추가해야 한다면 어떤 절차가 필요한지 확인 부탁드립니다.
```

## 5. 자주 막히는 지점

| 증상 | 해결 방법 |
| --- | --- |
| 주소를 브라우저에서 열었더니 오류나 빈 화면 | MCP는 일반 웹페이지가 아닙니다. ChatGPT의 연결 화면에서 등록하고 첫 도구 조회로 확인합니다. |
| 연결 실패·서버를 찾지 못함 | URL이 `/api/mcp`까지 정확한지, 끝에 공백이나 따옴표가 없는지 확인합니다. 일시 오류면 잠시 후 한 번 다시 시도합니다. |
| API 키나 OAuth 설정을 계속 요구함 | 인증 없음으로 설정했는지 확인합니다. 개인 ChatGPT 비밀번호나 임의 토큰을 넣지 않습니다. |
| 설치했는데 도구가 없거나 이전 도구 목록이 보임 | 플러그인 연결의 새로고침을 실행하고 새 대화를 시작합니다. [공식 메타데이터 갱신 안내](https://developers.openai.com/plugins/deploy/connect-chatgpt) |
| AI가 도구 대신 일반 지식으로 답함 | @로 아카이브를 지정하고 실제 `get_archive_scope` 호출부터 요청합니다. |
| 원문 그림이 없거나 이미지 도구가 실패함 | 텍스트만 확인한 것인지 구분하고, 반환된 공식 출처·웹 사례에서 직접 대조합니다. 모든 과제에 그림이 있지는 않습니다. |
| 429·요청 제한·사용량 한도 | 한 번에 과제 5개 이내, 비교는 2개부터 사용합니다. 서버 요청 제한과 ChatGPT 계정 사용량 제한은 구분합니다. |

## 6. 해제와 확인 범위

더 쓰지 않을 때는 플러그인 상세의 제거 기능을 사용하고, 별도 MCP 연결이 남아 있다면 그 연결도 해제합니다. 조직에서 배포한 항목은 관리자에게 문의합니다. 플러그인 제거와 별도 연결 해제의 차이는 [OpenAI 공식 안내](https://learn.chatgpt.com/docs/plugins)에 있습니다. 이전 대화 기록은 별도로 관리합니다.

이 문서는 공식 제품 문서의 화면 절차와 운영 서버의 SDK 검증을 근거로 작성했습니다. 선생님의 개별 ChatGPT 계정에서 설치·대화가 완료됐다는 보장은 아닙니다. 첫 조회가 성공한 뒤 사용하세요. 이 아카이브를 공식 플러그인 디렉터리에 심사·등록했다는 뜻도 아닙니다.
