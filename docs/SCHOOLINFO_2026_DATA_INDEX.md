# 2026학년도 자료 범위와 검증 기준

이 문서는 교사용 공개 저장소의 자료 안내입니다. 실제 학교 문서·운영 DB·원문 그림·개인 조회 결과는 이 저장소에 포함하지 않습니다. 코드 이용에는 MIT 라이선스를 적용하며, 공식 자료의 권리와 이용 조건은 각 출처를 따릅니다.

## 자료를 읽는 방법

- [웹 라이브러리](https://suhaeng-math.vercel.app/cases)에서 과목·학년도·학기·지역을 고르고 원문 표와 공식 출처를 확인합니다.
- [MCP 연결 안내](MCP_CONNECTION.md)를 따라 지원하는 개인 AI에서 검색·원문·채점표·성취기준·그림을 조회할 수 있습니다. 실제 운영 연결 확인 상태도 해당 문서에서 확인합니다.
- MCP 연결을 사용할 수 없으면 [Python 조회 도구와 연구 지침](AI_RESEARCH_GUIDE.md)을 사용합니다.
- 자료 수집과 추출을 직접 재현하려면 [수집·추출 실습](SCHOOLINFO_WORKFLOW.md)을 읽습니다. 공유판은 가상 예제로 먼저 실행할 수 있습니다.

## 검증한 최종 자료판

2026년 11월 9일 검증한 v5 자료판은 공개 원문 항목 21,416개, 학교·과목·평가계획 사례 9,190건, 공개 항목이 있는 학교 1,868개교입니다. 이전 1학기 중심 공개판의 11,310항목보다 10,106개 늘었습니다. 데이터 검증과 실제 운영 반영 상태는 [상세 업데이트 보고서](UPDATE_REPORT_2026_SECOND_SEMESTER.md)의 15절에서 구분합니다.

학교 대조 명부는 2,584행이며 저장된 학교는 2,343개교입니다. 이 수치들은 분모와 상태가 다르므로 서로 같은 전국 전체 건수로 해석하지 않습니다. 학교별 수집 이력·원문 해시·미확보 및 검토 사유의 운영 원장은 별도로 보존합니다.

공식 성취기준 목록은 2015 개정 10과목 199개, 2022 개정 15과목 254개로 총 25조합·453개입니다. 같은 코드라도 교육과정에 따라 문장이 다릅니다. 원문에 적힌 과목명과 공식 목록의 대응이 확인되지 않은 자료는 임의로 연결하지 않습니다. [성취기준 비교 근거](ACHIEVEMENT_STANDARD_COMPARISON.md)

## 읽을 때 구분할 점

- 미검출은 미개설이 아닙니다. 원문 미확보, 추출 실패, 교육과정 판별 유보, 개설 여부 미확인을 구분합니다.
- 공개 항목 수는 서로 다른 평가 설계의 수와 같지 않습니다. 같은 평가가 총괄표와 상세표의 다른 구간에 포함될 수 있습니다.
- 경향 화면의 보존 사례 수에는 검토 상태인 사례도 포함됩니다. 공개 과목별 증감은 상세 보고서의 공개 집계를 사용합니다.
- ‘교육과정 확인 필요’ 자료는 2015 또는 2022로 단정하지 않습니다. 성취기준 비교는 교육과정·과목·코드를 함께 확인합니다.
- 원문 그림으로 대응 추출문을 접어 표시하는 경우가 있습니다. 이미지 실패 시 보존된 추출문을 다시 확인하고 공식 원문과 대조합니다.
- 평가계획은 실제 수업 실행이나 학습효과의 증거가 아닙니다. 근거 점수와 표시 순서를 학교 순위나 설계 품질로 해석하지 않습니다.

새로운 분석 결과에는 실제 읽은 범위와 과제 ID·공식 출처를 붙이고, 원문 사실·AI 해석·재설계 제안을 구분합니다. 개인 결과는 `research/outputs/`에 보관하며 공개 저장소에 자동으로 올리지 않습니다.
