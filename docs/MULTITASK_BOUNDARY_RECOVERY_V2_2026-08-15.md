# 다중 수행평가 원문 경계 복원 v2

작성일: 2026-08-15  
상태: 후보 DB 검증 완료. 2026-08-15 운영 데이터 반영 및 Production 배포 준비 완료.

## 목적

한 학교 평가계획의 여러 수행평가가 하나의 원문 묶음으로 남은 경우, 원문 표의 `평가 영역명` 값이 명확한 항목만 개별 수행평가로 분리한다. 제목을 생성하거나 원문 표의 셀·행을 바꾸지 않는다.

## 판정 기준

후보는 다음을 모두 만족해야 한다.

- 원문 표에 명시된 단일 `평가 영역명`이 제목으로 확인된다.
- 해당 조각 안에 수행평가 구조 표지와 과목 성취기준 근거가 있다.
- 기존 공개 항목 또는 같은 회수 묶음과 제목이 중복되지 않는다.
- 다중 평가영역·성취기준 표 분할·행 병합 오류처럼 경계 자체를 흔드는 표 구조 경고는 제외한다.
- 긴 표, 빈 열, 비정형 머리글처럼 표현 복원 가능한 경고만 허용하고 실제 브라우저 렌더링 검사를 통과해야 한다.
