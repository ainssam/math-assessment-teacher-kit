# Claude에서 수학 수행평가 아카이브 연결하기

확인 기준: 2026년 11월 9일. [공통 시작 안내와 활용 질문](TEACHER_AI_GUIDE.md)

**Claude의 맞춤 커넥터에 서버 주소를 추가하고, 새 대화에서 켜면 됩니다.** PC 웹브라우저를 기준으로 설명합니다. 원격 커넥터이므로 로컬 설정 파일 수정이나 프로그램 설치는 필요 없습니다.

## 1. 내 계정에서 사용할 수 있는지 확인하세요

| 계정·환경 | 확인 내용 |
| --- | --- |
| Free | 공식 안내상 맞춤 원격 커넥터를 지원하며 1개까지 추가할 수 있습니다. 기존 커넥터가 있다면 현재 등록 상태를 먼저 확인하세요. |
| 개인 유료 계정 | 맞춤 커넥터를 지원합니다. 답변 생성에는 해당 구독의 사용량 한도가 적용됩니다. |
| Team·Enterprise | 조직 소유자 등 추가 권한을 가진 관리자가 먼저 등록해야 합니다. 구성원은 허용된 항목을 연결합니다. |
| 웹·Claude Desktop | 원격 맞춤 커넥터의 최초 등록에 권장되는 경로입니다. |
| iOS·Android | 같은 계정에 연결한 서비스를 사용할 수 있습니다. 모바일 설치는 베타이므로 처음 등록은 웹이나 데스크톱에서 진행하는 편이 좋습니다. |

지원 계정은 [맞춤 커넥터 공식 안내](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp), 모바일과 대화별 활성화는 [커넥터 사용 공식 안내](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)를 확인했습니다.

## 2. 맞춤 커넥터를 추가하세요

1. Claude에 로그인하고 [커넥터 관리 화면](https://claude.ai/customize/connectors)을 엽니다.
2. 추가(**Add** 또는 **+**)를 누릅니다.
3. 맞춤(**Custom**) → 웹(**Web**)을 고릅니다. 화면에 맞춤 커넥터 추가 버튼이 바로 보이면 그 버튼을 사용합니다.
4. 이름과 서버 URL을 넣고 계속 진행합니다.

| 항목 | 입력할 값 |
| --- | --- |
| 이름 | `수학 수행평가 아카이브` |
| 원격 MCP 서버 URL | `https://suhaeng-math.vercel.app/api/mcp` |
| 인증 방식 | **로그인 없음 / No sign in** |
| 추가 요청 헤더·API 키 | 입력하지 않습니다. |
| 전송 방식이 표시될 때 | Streamable HTTP |

URL 복사용:

```text
https://suhaeng-math.vercel.app/api/mcp
```

5. Claude가 감지한 인증 설정을 검토합니다. 이 서버는 공개 자료 조회용이므로 로그인 없음을 선택합니다. OAuth 클라이언트나 별도 토큰을 만들 필요가 없습니다.
6. 추가를 완료하고 도구 목록이 확인되면 커넥터 화면으로 돌아옵니다. 연결 버튼이 표시되면 연결 상태까지 확인합니다.

화면 이름과 인증 선택의 공식 근거는 [Anthropic의 등록 절차](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)에 있습니다. Streamable HTTP와 인증 없는 서버도 지원하는 것은 [공식 개발 안내](https://claude.com/docs/connectors/building)에서 확인했습니다.

커넥터 디렉터리에서 이름으로 검색되지 않아도 맞춤 URL로 추가할 수 있습니다. 이 아카이브는 디렉터리 심사·등록을 마친 서비스라고 안내하지 않습니다.

## 3. 새 대화에서 켜고 첫 조회를 하세요

1. 새 대화를 엽니다.
2. 입력창의 **+** → 커넥터(**Connectors**)에서 ‘수학 수행평가 아카이브’를 켭니다.
3. 아래 질문을 보냅니다.

```text
수학 수행평가 아카이브의 get_archive_scope를 실제 호출해줘.
현재 공개 과제 수, 사례 수, 학교 수, 학년도·학기, 조회 시각을 알려줘.
도구를 사용할 수 없으면 연결됐다고 말하지 말고 오류를 알려줘.
```

도구 실행 결과가 반환되는지 확인합니다. 도구 사용 허용 창이 나타나면 대상이 이 아카이브의 읽기 도구인지 확인하고 해당 조회를 허용합니다. 처음부터 모든 도구의 상시 허용을 설정할 필요는 없습니다.

대화별 커넥터 활성화 방법은 [공식 사용 안내](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)를 따릅니다. 등록 후 목록에 보이는 것과 현재 대화에서 실제 도구를 쓰는 것은 구분하세요.

처음에는 다른 커넥터를 함께 켤 필요 없이 아카이브만 선택하면 도구 실행을 확인하기 쉽습니다. 여섯 도구는 범위 확인, 사례 검색, 과제 상세, 공식 성취기준, 2~4개 과제 비교, 원문 그림 조회입니다. 자료 수정·삭제 도구는 없습니다.

## 4. 이어서 이렇게 부탁하세요

```text
2026학년도 2학기, 2022 개정 기하 과제를 최대 5개 찾아줘.
실제 반환된 ID로 수행 내용과 채점표를 읽고, 학교·학기·공식 출처를 붙여줘.
검색에 일치한 사례 수와 이번에 읽은 과제 수는 구분해줘.
채점표 수식이나 배점 열이 이상하면 제공되는 원문 그림을 조회해줘.
그림을 읽지 못하면 확인하지 못했다고 밝혀줘.
```

이후 [성취기준 비교·1학기 자료 찾기·4차시 재설계 질문](TEACHER_AI_GUIDE.md#4-수업-준비에-바로-쓰는-질문)으로 이어 갈 수 있습니다. 자료가 없는 조건에서는 숫자나 학교를 추측하지 않게 요청하세요.

웹이나 데스크톱에서 연결한 뒤 모바일에서도 같은 계정인지 확인하고 대화의 커넥터를 켭니다. [공식 환경별 사용 안내](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)

## 5. 학교 조직 계정에서는

관리자에게 다음 문안을 전달할 수 있습니다.

```text
수업 준비용 공개 수학 수행평가 아카이브 커넥터를 추가하고 싶습니다.
이름: 수학 수행평가 아카이브
URL: https://suhaeng-math.vercel.app/api/mcp
방식: 원격 Streamable HTTP / 로그인 없음 / 추가 요청 헤더 없음
공개 평가계획·채점표·성취기준·원문 그림을 읽는 여섯 도구만 제공합니다.
우리 조직의 커넥터 설정에서 추가·사용을 허용해 주실 수 있는지 확인 부탁드립니다.
```

조직의 소유자 등 등록 권한을 가진 관리자가 조직 설정 → 커넥터에서 먼저 추가하고, 구성원은 자신의 커넥터 화면에서 연결해 대화에 켭니다. 구체적인 Enterprise 역할별 권한은 [공식 조직 등록 안내](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)를 따릅니다. 이 공개 서버는 조직용 공유 비밀번호나 API 키를 발급하지 않습니다.

## 6. 자주 막히는 지점

| 증상 | 해결 방법 |
| --- | --- |
| Free에서 추가할 수 없다고 나옴 | 공식 안내의 맞춤 커넥터 1개 제한과 이미 등록한 항목을 확인합니다. 기존 업무용 커넥터를 지우기 전에는 영향과 복구 방법을 확인하세요. |
| 추가 버튼이 없음 | PC 웹의 관리 화면과 계정·조직을 확인합니다. 조직 계정이면 관리자 등록이 필요한지 문의합니다. |
| 로그인·OAuth·API 키를 요구함 | 로그인 없음 설정과 URL을 확인합니다. 개인 Claude 비밀번호나 임의 토큰을 서버 인증에 넣지 않습니다. |
| 연결됐는데 Claude가 일반 지식만 답함 | 현재 대화의 커넥터가 켜졌는지 확인하고 실제 `get_archive_scope` 호출을 요청합니다. |
| 모바일에서 추가 기능이 없거나 불안정함 | 최초 등록은 PC 웹에서 하고, 같은 계정의 모바일 대화에서 활성화를 확인합니다. |
| URL을 브라우저로 열었더니 오류 | 일반 웹페이지가 아닌 MCP 주소입니다. 커넥터 등록 후 실제 도구 호출로 확인합니다. |
| 연결 시간 초과·네트워크 오류 | URL을 다시 확인한 뒤 잠시 후 재시도합니다. 계속 실패하면 오류 문구를 남겨 주세요. 급한 자료는 [웹앱](https://suhaeng-math.vercel.app/cases)에서 확인할 수 있습니다. |
| 429·요청 제한·AI 사용량 소진 | 한 번에 과제 5개 이내, 비교는 2개부터 시도합니다. 대량 자동 조사를 줄이고 해당 제한이 풀린 뒤 사용합니다. |
| 이미지 도구가 실패하거나 그림이 없음 | AI가 실제 그림까지 봤는지 구분하고 공식 출처나 웹 사례에서 직접 확인합니다. 그림 없는 과제도 있습니다. |

Claude의 원격 연결은 선생님의 PC에서 서버로 직접 이어지는 방식이 아니라 Anthropic의 클라우드를 거칩니다. PC에서 주소가 열린다는 것만으로 Claude의 연결 성공을 판단하지 않습니다. [공식 네트워크 설명](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

## 7. 끄기·삭제와 확인 범위

현재 대화에서만 쉬려면 커넥터 토글을 끕니다. 등록 자체를 없애려면 커넥터 관리 화면의 해당 항목에서 제거 기능을 사용합니다. 조직이 등록한 항목은 관리자에게 문의하세요. 이미 생성한 대화와 답변은 별도로 관리합니다.

이 설명은 공식 제품 문서를 기준으로 작성했습니다. 운영 서버는 공식 MCP SDK 연결과 여섯 도구 검사를 완료했지만, 모든 Claude 계정·기기에서 등록을 직접 완료한 것은 아닙니다. 자신의 계정에서 3절의 조회 성공을 확인한 뒤 사용하세요.
