# 선생님을 위한 ChatGPT·Claude 연결과 활용 안내

확인 기준: 2026년 11월 9일. 메뉴 이름은 언어·계정·서비스 업데이트에 따라 달라질 수 있습니다.

**평소 쓰는 AI에 아래 주소를 한 번 연결하면, 수학 수행평가 아카이브의 실제 자료를 찾아 읽고 비교하도록 부탁할 수 있습니다.** GitHub 내려받기, 프로그램 설치, Python 실행은 필요 없습니다.

## 1. 사용하는 AI를 고르세요

| 사용하는 곳 | 따라 할 안내 | 먼저 확인할 점 |
| --- | --- | --- |
| ChatGPT 웹 | [ChatGPT 연결 방법](CHATGPT_MCP_GUIDE.md) | 현재 공식 안내의 플러그인 → 사용자 MCP 추가 경로. 계정·워크스페이스 권한에 따라 메뉴 제공 여부가 다릅니다. |
| Claude 웹·데스크톱 | [Claude 연결 방법](CLAUDE_MCP_GUIDE.md) | 맞춤 커넥터를 추가합니다. 공식 안내상 Free도 지원하며 맞춤 커넥터는 1개까지입니다. |
| 학교·교육청 조직 계정 | 각 안내의 ‘학교 조직 계정’ 항목 | 관리자가 먼저 허용하거나 추가해야 할 수 있습니다. |
| Codex 또는 직접 명령 실행 | [MCP 기술 안내](MCP_CONNECTION.md) · [Python 조회 안내](AI_RESEARCH_GUIDE.md) | 이미 해당 도구를 사용하는 선생님을 위한 별도 경로입니다. |

ChatGPT의 현재 연결 경로는 [OpenAI 공식 안내](https://developers.openai.com/plugins/deploy/connect-chatgpt), Claude의 지원 범위는 [Anthropic 공식 안내](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)를 확인했습니다. 유료 구독만으로 모든 계정의 메뉴 제공을 보장하지는 않습니다.

## 2. 입력할 값은 이것뿐입니다

| 항목 | 입력할 내용 |
| --- | --- |
| 이름 | 수학 수행평가 아카이브 |
| 서버 주소 | `https://suhaeng-math.vercel.app/api/mcp` |
| 설명이 필요할 때 | 학교알리미 공개 평가계획의 수행 내용·채점표·성취기준·원문 그림을 조회하고 비교합니다. |
| 인증 | 없음. ChatGPT는 인증 없음, Claude는 로그인 없음으로 선택합니다. |
| 전송 방식이 표시될 때 | Streamable HTTP |
| API 키·토큰·추가 요청 헤더 | 입력하지 않습니다. |

서버 주소 복사용:

```text
https://suhaeng-math.vercel.app/api/mcp
```

이름은 알아보기 쉽게 바꿔도 됩니다. 주소는 `/api/mcp`까지 그대로 입력하세요. 연결 화면의 서비스 계정 로그인과 이 아카이브의 인증 없음은 별개입니다.

## 3. 연결한 직후에는 이 질문부터 보내세요

```text
연결한 ‘수학 수행평가 아카이브’ 도구를 실제로 사용해줘.
get_archive_scope를 호출해서 현재 공개 과제 수, 사례 수, 학교 수,
제공하는 학년도와 학기, 조회 시각을 알려줘.
도구를 사용할 수 없다면 연결됐다고 말하지 말고 오류를 알려줘.
```

AI의 답변에서 **실제 도구 실행 표시와 조회 결과**를 확인합니다. 이름이 목록에 보이거나 AI가 “연결되었습니다”라고 말한 것만으로는 충분하지 않습니다. 과제 수는 업데이트로 바뀔 수 있으므로 이 문서의 고정 숫자와 맞추려고 하지 마세요.

## 4. 수업 준비에 바로 쓰는 질문

아래 질문의 과목·학기·지역·차시만 바꿔 사용하세요. 자료가 없으면 없는 상태와 확인하지 못한 범위를 밝혀 달라고 요청하는 것이 좋습니다.

### 처음 사례를 찾을 때

```text
수학 수행평가 아카이브로 2026학년도 2학기, 2022 개정 기하 과제를
최대 5개 찾아줘. 실제 반환된 ID로 수행 내용과 채점표를 읽고
학교, 지역, 학기, 평가명, 배점·반영 비율, 공식 출처를 표로 정리해줘.
원문에 없는 값은 추측하지 말고 ‘미확인’으로 남겨줘.
검색에 일치한 사례 수와 이번에 실제로 읽은 과제 수는 구분해줘.
```

### 같은 성취기준으로 비교할 때

```text
2022 개정 공통수학2의 공식 성취기준 목록을 먼저 조회해줘.
내가 기준을 고르면 그 코드에 연결된 2026학년도 2학기 과제를 찾아줘.
서로 다른 학교의 과제 2개를 고를 수 있으면 본문과 채점표를 읽고,
같은 기준을 어떤 활동과 채점 요소로 평가하는지 비교해줘.
코드뿐 아니라 교육과정과 공식 기준 문장도 대조해줘.
```

### 기존 1학기 자료를 참고할 때

```text
2026학년도 1학기, 2022 개정 공통수학1 과제를 최대 5개 찾아줘.
현재 공개된 정정본을 조회하고 원문 확인 메모(source_notes)도 알려줘.
우리 지역은 충청남도야. 결과가 없으면 지역 조건을 풀지 말고 먼저 알려줘.
```

### 두 과제의 채점표를 깊게 읽을 때

```text
방금 실제로 조회한 과제 중 내가 고른 2개를 비교해줘.
수행 내용, 성취기준, 채점 요소, 점수 단계, 과정 증거를 대조하고
각 설명에 해당 과제의 출처를 붙여줘.
수식이나 배점 열이 이상하면 원문 그림을 조회해서 확인해줘.
그림이 없거나 읽지 못하면 확인하지 못했다고 밝혀줘.
```

### 우리 반 조건에 맞게 재설계할 때

```text
방금 읽은 실제 과제 2개를 근거로 우리 반 수행평가 초안을 제안해줘.
조건은 4차시, 28명, 개인 활동, 특별한 유료 도구 없음이야.
학생이 설명할 수 있는 수학적 사고와 근거를 평가하고 싶어.
원문에서 확인한 사실 / 너의 해석 / 새로 제안한 설계를 구분해줘.
활동 순서, 교사가 관찰할 장면, 학생이 남길 최소한의 증거,
채점기준 초안을 만들되 원래 학교의 채점표로 오해하지 않게 표시해줘.
```

더 읽고 싶다면 “다음 페이지가 있는지 먼저 확인하고, 추가로 읽을 양을 알려줘”라고 요청하세요. 처음부터 전체 학교를 자동 순회하도록 요구하면 시간과 AI 사용량이 커질 수 있습니다.

## 5. 답변을 사용할 때 확인할 것

- **원문과 출처:** 학교·기간·공식 원문 링크가 있는지, 실제로 읽은 본문과 채점표에 근거하는지 봅니다.
- **확인 범위:** 검색 일치 수와 읽은 수, 본문 잘림, 원문 주의사항을 구분합니다. 그림이 없는 자료도 있습니다.
- **교육과정:** 2015·2022 개정, 같은 이름의 과목, 판별 유보 자료를 섞지 않습니다.
- **교사 판단:** 미검출은 미개설이 아니며, 근거 점수는 설계 품질이나 학교 순위가 아닙니다. 재설계는 새 제안입니다.

이 서버는 공개 자료를 읽는 여섯 도구를 제공합니다. 별도 AI 분석 요금을 청구하거나 AI 로그인·API 키를 받지 않으며, 답변 생성은 선생님의 AI 계정에서 이루어집니다. 해당 서비스의 사용량 한도는 적용됩니다. 학생 개인정보나 비공개 성적 자료는 연결 실습에 필요하지 않습니다.

## 6. 연결이 안 되거나 사용을 끝낼 때

플랫폼별 안내의 문제 해결 표를 확인하세요. 급하게 수업 자료가 필요하면 [웹앱에서 직접 검색](https://suhaeng-math.vercel.app/cases)하고 [성취기준 비교](https://suhaeng-math.vercel.app/standards)를 사용할 수 있습니다.

질문을 남길 때는 사용하는 서비스·개인/조직 계정 여부·메뉴 이름·오류 문구만 적으면 됩니다. [GitHub Issues](https://github.com/ainssam/math-assessment-teacher-kit/issues)에 비밀번호·토큰·학생 자료를 올리지 마세요.

연결을 해제해도 이미 만든 AI 대화와 답변이 자동 삭제되지는 않습니다. 각 AI 서비스에서 대화 기록을 별도로 관리합니다.

## 확인한 범위

운영 서버의 공식 MCP SDK 연결·여섯 도구 119개 검사와 공식 성취기준 25조합·453개 대조를 완료한 상태입니다. 이 안내의 화면 절차는 위 공식 제품 문서를 기준으로 작성했습니다. 모든 선생님의 ChatGPT·Claude 계정에 직접 로그인해 등록·대화를 검증한 것은 아닙니다. 실제로 사용하는 계정에서는 3절의 첫 조회로 연결을 확인하세요.
